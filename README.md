🏠 Airbnb Price Prediction using Linear Regression

This project focuses on building a machine learning model to predict Airbnb listing prices using real-world data. The workflow includes data cleaning, exploratory data analysis, feature engineering, and model training using Linear Regression.

📌 Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
📊 Project Overview
1. Data Loading

The dataset is imported from a CSV file and initial exploration is performed to understand its structure.

2. Exploratory Data Analysis (EDA)

The dataset is analyzed to understand its structure, data types, and statistical properties. Missing values and duplicate records are also checked to ensure data quality.

3. Data Cleaning

Several unnecessary columns that do not contribute to prediction are removed. Missing values are handled by either dropping or filling them based on their importance.

4. Feature Engineering

Categorical variables are converted into numerical format using encoding techniques to make them suitable for machine learning algorithms.

5. Model Training

The dataset is split into training and testing sets. A Linear Regression model is trained on the training data to learn relationships between features and price.

6. Model Evaluation

The model is evaluated using standard regression metrics such as Mean Absolute Error (MAE) and R² Score to measure prediction accuracy.

📈 Data Visualization

Data distributions and feature relationships are visualized using histograms and correlation heatmaps to better understand patterns in the dataset.

🎯 Project Goal

The main objective of this project is to build a complete machine learning pipeline that includes data preprocessing, feature engineering, and predictive modeling for real-world regression problems.
